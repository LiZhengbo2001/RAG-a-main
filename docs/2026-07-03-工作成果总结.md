## 二、各项改动详解

### 1. 检索阈值 Bug 修复

**问题**：`rag_pipeline.py` 中检索结果质量判断只有一个条件：`all(score < 3.0)`。但 `score` 可能来自 bge-reranker（raw logit，范围 -10 到 +10）或 Milvus 余弦相似度（范围 -1 到 1）。当 candidates ≤ 5 时 reranker 被跳过，chunk 只有余弦相似度，永远小于 3.0，导致所有检索结果都被误判为"不相关"并 fallback 到联网搜索。

**修复**：拆分为两条判断路径——有 `rerank_score` 时用 3.0 阈值，只有 `score` 时用 0.3 阈值（余弦相似度底线）。

### 2. DeepSeek 切换

| 改动点 | 内容 |
|--------|------|
| .env | LLM_BASE_URL 改为 api.deepseek.com/v1，LLM_API_KEY 改为 DeepSeek API Key，模型名改为 deepseek-chat |
| core/llm.py | tokenizer 从 cl100k_base 改为 o200k_base（更接近 DeepSeek 实际编码） |
| core/langchain_agent.py | ChatOllama 改为 ChatOpenAI，base_url 不再 strip /v1 |
| requirements.txt | 新增 langchain-openai |

保留 Ollama 的部分：embedding（shaw/dmeta-embedding-zh）和图片理解（minicpm-v:8b），因为 DeepSeek 没有这些能力。

### 3. CORS 放开

`main.py` 的 `allow_origins` 从 `["http://localhost:5173"]` 改为 `["*"]`，使聊天挂件可以嵌入任意域名的官网跨域调用。

### 4. 匿名 Widget API

**新建文件**：

- `schemas/widget.py` — WidgetChatRequest（visitor_id 代替 JWT）、FeedbackRequest、LeadRequest
- `api/widget_chat.py` — 三个端点：
  - `POST /api/widget/chat/stream` — 匿名流式聊天
  - `GET /api/widget/suggestions` — 推荐问题列表
  - `POST /api/widget/feedback` — 用户反馈

**修改文件**：

- `models/conversation.py` — Conversation 表新增 `visitor_id` 字段（支持匿名访客追踪）
- `services/rag_pipeline.py` — `run_stream()` 增加 `visitor_id` 参数，`_ensure_conversation()` 支持 24 小时内复用匿名会话
- `main.py` — 注册 Widget 路由

**设计要点**：

- 认证用户和匿名访客共用同一个 `run_stream()` 流水线，区别只在于传 `user_id` 还是 `visitor_id`
- 匿名会话 24 小时内复用，刷新页面不丢失对话
- Widget API 路由独立于管理后台 API，可分别做速率限制和监控

### 5. 结构化 Prompt

将原来单一通用 `SYSTEM_PROMPT` 拆分为三个场景模板：

| Prompt | 使用场景 | 特点 |
|--------|---------|------|
| BUSINESS_PROMPT | 有检索结果 | 严格限定仅依据参考文档、禁止 AI 身份暴露、固定来源引用格式、禁止主观评价 |
| NO_RESULT_PROMPT | 检索无结果 | 固定兜底话术加引导联系人工客服，不给 LLM 编造空间 |
| CHITCHAT_PROMPT | 闲聊 | 3 句以内、口语化、末尾推荐常见问题引导回业务对话 |

`config.py` 新增 `COMPANY_NAME`、`CUSTOMER_SERVICE_PHONE`、`AGENT_NAME`、`LEAD_TIMEOUT_SECONDS`、`SUGGESTED_QUESTIONS` 配置项。`.env` 中设置这些值即可定制客服人设。

### 6. 意图路由

`core/intent_router.py` 在检索前判断用户意图：

- **闲聊**（问候、感谢、告别）：不调检索流水线，直接走 CHITCHAT_PROMPT 模板秒回
- **业务问题**：走完整 RAG 流水线

优化点：短消息（小于 10 字且关键词命中）直接跳过 LLM 分类，省一次 API 调用。

### 7. gitignore 完善

排除了 `.venv/`、`.env`、`__pycache__/`、`*.pyc`、`.idea/`、`*.db`、`storage/documents/`、模型文件、`node_modules/`、`dist/`、日志等不应提交的文件。
